## The entry

🌅

One emoji. Nothing else. A sunrise over the sea — the first morning
of the trip, golden light spilling over water, the exact moment that
makes a stranger want to book the flight. The island emoji is what
everyone else sends; the sunrise is what the trip actually feels like.
No words are needed: the light does all the persuading.

## How it works

`main.ts` writes the single emoji to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```
