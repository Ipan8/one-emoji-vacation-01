The entry is one emoji: 🌅 — a sunrise over the sea, the first morning of the trip, golden light over water. Not the island cliche: the sunrise is the feeling that makes a stranger book the flight.

Run `node main.ts` to write the emoji to `/output/entry.txt`.

One glyph, no words — the light does all the persuading.
